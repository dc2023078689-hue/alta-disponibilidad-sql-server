# SQLHA - Proyecto Unidad II de Sistemas Operativos I

Sitio web estatico para GitHub Pages. El contenido describe un **diseno propuesto** y una validacion estatica; **no representa** pruebas realizadas en un clúster real.

## Publicacion en GitHub Pages
1. Crear un repositorio en GitHub, por ejemplo `alta-disponibilidad-sql-server`.
2. Subir a la raiz del repositorio todos los archivos de esta carpeta, incluida la carpeta `documentos`.
3. En GitHub abrir Settings > Pages.
4. En Source, elegir Deploy from a branch; rama `main` y directorio `/(root)`.
5. Esperar la URL publica proporcionada por GitHub Pages. **No hay URL publicada por este paquete**.
6. Verificar uno por uno los 5 enlaces de descarga desde la web publicada.
7. Crear carpeta de entrega en Drive/OneDrive y agregar su URL real donde corresponda.

## Archivos
- `index.html`, `styles.css`, `script.js`: sitio responsive, sin dependencias remotas.
- `assets`: cuatro diagramas tecnicos.
- `documentos`: informe DOCX y PDF, presentacion PPTX y PDF, material reproducible ZIP.

## Aviso de integridad
No se han generado capturas falsas de SQL Server ni se presenta una simulacion logica como validacion real de disponibilidad.
