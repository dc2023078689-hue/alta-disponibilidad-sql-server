# Investigacion de la Unidad I

Este directorio conserva **el inventario de los 42 PDF y los enlaces facilitados** junto con el proyecto. Los PDF originales no estan publicados en el sitio publico para respetar posibles restricciones de derechos de autor.

- `indice_archivos_unidad_I.csv`: listado de archivos recibidos, grupo, tamano y SHA-256.
- `enlaces_proporcionados_unidad_I.md`: enlaces facilitados en seis archivos TXT (sin verificacion editorial individual).
- `index.html`: catalogo HTML navegable.

**Importante:** contar 42 archivos PDF no equivale a contar 42 publicaciones diferentes, pertinentes o verificadas. El informe se debe cotejar fuente por fuente antes de presentarlo como completo.
